## 📌 Description
Computer vision application running YOLOv8 object detection inference over live video streams and image feeds with Streamlit UI.

---

## 🛠️ Architecture & Highlights
- **Production Modular Design**: Standard clean code layout with runnable script entry point.
- **Extensible**: Ready for cloud deployment, Docker microservice wrapping, or educational analysis.

---

## 📦 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sparkx313/dl-yolov8-object-detection-ui.git
   cd dl-yolov8-object-detection-ui
   ```

2. **Run the entry point**:
   ```bash
   python yolo_app.py
   ```
